🎠 Slider de Viagens

Projeto desenvolvido para praticar JavaScript, trabalhando com manipulação do DOM, eventos e CSS avançado (animações e responsividade). A aplicação exibe um carrossel de destinos de viagem com transições animadas entre banner principal e miniaturas.

📚 Conceitos praticados

- Manipulação do DOM
- addEventListener()
- querySelector() e querySelectorAll()
- classList (add/remove)
- appendChild() e prepend()
- Animações com @keyframes
- Media queries (responsividade)
- Reflow forçado para reiniciar animações
- Manipulação dinâmica de elementos HTML

💻 Sobre o projeto

A proposta foi criar um slider/carrossel interativo de destinos de viagem (Bali, Paris, Roma, Veneza), com transição animada entre o item ativo e as miniaturas, incluindo textos, imagens e botões de navegação.
Ao clicar nas setas, o carrossel avança ou retrocede reorganizando os itens no DOM e disparando animações de entrada e saída.

🔍 Funcionalidades

- Navegar entre destinos com setas (próximo/anterior)
- Exibir banner com título, descrição e botões do destino ativo
- Miniaturas clicáveis dos demais destinos
- Animações de transição entre os slides
- Layout responsivo para mobile
